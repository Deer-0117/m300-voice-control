同步目标为 `Deer-0117/m300-voice-control` 的 `main`。本轮以通信盒当前 `flight-panel-20261105-v7` 为依据，保留 11 月 2 日已发布内容，补齐此后的源码、测试和说明。此次 GitHub 同步不部署或重启设备，也不启动飞行任务。

## 新增与修复

- 语音入口：50/60 改为“语音输入任务”，只准备新的录音会话；等待 API 候选后，55/65 才确认执行，不再默认启动任意气球任务。
- M300 控制权兼容：原生控制权回调不支持时使用经过检查的 `CONTROL_DEVICE` 遥测；过期、遥控器接管和释放失败仍保留停止及阻止自动重获控制权的约束。
- 本地视觉：整合 Conti 固定提交 `75469fe8de98bc8e915f544e543010f49be8ee9a` 的 YOLO/HSV 选择器、像素模块、入口和配套测试。默认使用本地 YOLO/TensorRT 加 HSV 颜色分组；画面不调用 API，语音及文本任务解析保留。
- 无目标保护：启动最多等待 5 秒，缺目标或缺有效画面时明确报错，不初始化飞控。执行中失去有效目标后清理旧目标与预测状态、停止继续追踪并持续减速至悬停；3 秒未恢复则结束并保留提示。
- 任务绑定：视觉回执校验任务令牌、开机周期、计划、行动序号、目标颜色和帧时间。旧帧在进入有状态选择器前即被拒绝，不能改变新任务的锁定或命中状态。
- 云台行为：面板任务保留当前云台姿态和模式，关闭启动/退出复位、自动扫描及近边缘找回；有效目标出现后仍可限速居中。
- 检测器切换：仅在两个 SDK 服务停止且没有活动任务标记时切换；只恢复原来运行的视觉服务，不自动启动 SDK。

颜色能力保持上游语义：蓝/紫、粉/红/橙、黄/绿三组，不能独立区分紫色与蓝色。纯 HSV 像素选项仅适用于随包黄/浅绿场景。详见[检测器说明](../onboard/code10/recognition/runtime/DETECTOR_SELECTION.md)及[视觉来源清单](../onboard/code10/recognition/VISION_SOURCE_MANIFEST.json)。
