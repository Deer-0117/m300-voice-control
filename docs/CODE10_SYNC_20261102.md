# 2026-11-02 通信盒当前源码同步

本轮目标为 `Deer-0117/m300-voice-control` 的 `main`，以 SSH 读取的 `code10` 当前 `flight-panel-20261102-v4` 为依据。此次 GitHub 同步只整理当前源码、公开模板、测试和说明，没有重新部署通信盒、切换维护状态或启动任务。

## 当前功能

设置列表为十项：仅显示/维护、开始测试、API联网、相机/姿态采样、部署/标定核验、Kalman预测模式、执行API语音任务、新增API语音任务、清除候选语音任务、停止测试。主画面另有六个同动作快捷入口；16 个唯一编号，共十个功能。新版拒绝旧 18–29 编号回调，C、双语布局和图标成套同步。

维护开关每次启动默认 ON。ON 在控制初始化前阻止 SDK 动作并禁止任务/采样；OFF 仅允许后续明确启动的真实测试任务。开关切换本身不调用飞控、云台或相机，忙状态、残留资源和未释放控制权会拒绝切换。成功切换清候选和旧任务门、预测复位基线，不能自动续跑。运行模式由控制层显式接口管理，不能把服务初始 `NO_FLIGHT=1` 当成 OFF 后的真实模式。

API 语音链路使用真实 interpret 生成候选，确认时校验本轮会话、开机周期、有效期及任务令牌；没有本地规则兜底冒充 API。新增语音任务采用两次点击：停止旧任务后录音，仅做 ASR，第二次点击再送 API 并执行新任务。任务进入控制前须通过执行端计划确认、录像回执与 COMMIT。停止/取消使旧代号和迟到结果失效；控制权释放失败仍保留阻止新任务的状态。

本轮也同步当前相机/姿态采样、严格时间标定检查、延迟 Kalman、运行部署核验和真实控制适配层源码。没有把采样完成或相对时移估计描述成有效物理时间标定，也没有验证 Kalman 的实飞收益。
