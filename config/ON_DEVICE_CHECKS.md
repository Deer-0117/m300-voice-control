# 现场接口验收

本清单针对尚未在线连接到的 M300/Jetson，不能由本机单元测试代替。

1. 用 `uname -m`、`cat /etc/os-release`、`cat /proc/device-tree/model` 核对本地交接记录中的 Orin NX/Ubuntu 22.04/ARM64。核对实际 PSDK 版本和机型/固件支持情况。
2. 使用设备自己的 SDK 头文件、库、平台配置、真实 RID 和账户信息编译桥接。停止旧的自主接近与同类 SDK 示例，避免多个控制器或重复订阅。
3. 保留已有软件解码器，核对 H.264 FIFO 只有一个生产者与一个读取者。检查图像索引五列、sidecar 三列、本次开机 `mono-v1` token。
4. 在两个飞行开关都为 0 时确认相机方向、固定镜头、图像时效、真实速度/航向/高度和语音识别。零开关下不得出现获取控制权或发送 Joystick 的调用。
5. 在 DJI Pilot 验证“查看计划/准备 → 确认执行”，以及未确认、拒绝、重新语音修改和暂停。计划变更后旧确认不生效。
6. 验证 Python 停止、API 超时、旧图片、旧遥测、失去控制权和旧响应到达时，真实非零输出均被阻止。
7. 验证飞控和相机机体系方向、航向角正方向、速度健康状态、home-relative 高度，并在受控条件下核对低速短时动作和制动响应。
8. 完成反馈由操作者核实。禁止把模型“看不见了”当作碰撞完成，禁止用本地测试数据替换设备状态。

初版无自动起飞/降落，必须人工起飞到允许高度后再交接给已确认任务。
